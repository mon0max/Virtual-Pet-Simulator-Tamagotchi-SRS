# Changelog

## v1.0.0 — 2026-11-10

Первая версия учебного веб-прототипа тамагочи для лабораторной работы №3.

- Создание питомца: имя 1–20 символов, выбор окраса, четыре начальных показателя по 50% (#2, PR #33).
- Кормление и поение: +20 к показателю, предел 100%, сообщения и автосохранение (#3, PR #34, squash merge).
- Игра: анимация, +15 счастья, −10 энергии, отказ при энергии ниже 10% (#4, PR #35).
- Загрузка прогресса из localStorage, русский адаптивный интерфейс.
- GitHub Actions: наличие основных файлов, синтаксис JavaScript, четыре автоматических теста.
- README со скриншотами и Wiki с процессом разработки.

Ограничение объёма: реализованы три выбранные задачи лабораторной, остальные требования полного ТЗ остаются в беклоге.
