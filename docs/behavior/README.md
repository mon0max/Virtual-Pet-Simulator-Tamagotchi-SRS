# Диаграммы поведения системы

## Диаграмма вариантов использования

[Открыть Use Case диаграмму](../use_case/use_case_diagram.png)

Актор **Пользователь** создаёт питомца, просматривает его показатели, кормит, поит и играет с ним. При открытии страницы симулятор восстанавливает прогресс из хранилища браузера. Создание питомца включает проверку имени и окраса. После создания и действий по уходу приложение пытается сохранить состояние.

## Диаграммы последовательности

1. [Создание питомца](sequence/create_pet_sequence.png). Проверка имени и окраса, установка начальных значений шкал, отображение и сохранение питомца.
2. [Кормление и поение](sequence/feed_and_water_sequence.png). Обновление сытости или утоления жажды с ограничением до 100% и обработка случая, когда шкала уже заполнена.
3. [Игра с питомцем](sequence/play_sequence.png). Проверка энергии, обновление счастья и энергии, запуск анимации при успешной игре.
4. [Сеанс ухода за питомцем](sequence/pet_care_session_sequence.png). Открытие страницы, восстановление прогресса или создание питомца, действия по уходу и повторное открытие с последним сохранением.
